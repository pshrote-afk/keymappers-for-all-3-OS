# Quick Productivity Hotkeys 

---

## 🔧 Shortcuts

| Keys | Action |
|------|---------|
| **RShift + C** | Open Google Calendar |
| **RShift + N** | Open Notion |
| **F6** | Play / Pause media |
| **Win + C** | Launch Chrome |
| **Win + B** | Launch Brave |
| **Ctrl + `** | Switch to previous browser tab |

---

## 🛠 Setup

You need:  
1. Install [AutoHotkey v2](https://www.autohotkey.com/)  
2. Create a file `hotkeys.ahk` and paste this script.  
3. Double-click it to run (will show green “H” in tray icon).
4. AHK is about 100–300× lighter than MS Word — you can leave it running 24/7 without any impact.
5. 5 minutes
