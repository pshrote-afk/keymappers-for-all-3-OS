# Quick Productivity Hotkeys 

---

## 🔧 Shortcuts

| Keys | Action |
|------|---------|
| **RShift + C** | Open Google Calendar |
| **RShift + N** | Open Notion |
| **F6** | Play / Pause media |
| **Win + C** | Launch Chrome |
| **Win + B** | Launch Brave |
| **Ctrl + `** | Switch to previous browser tab |

---

## 🛠 Setup

You need:  
1. Install [AutoHotkey v2](https://www.autohotkey.com/)  
2. Create a file `hotkeys.ahk` and paste this script.  
3. Double-click it to run (green “H” tray icon).
4. 10 minutes  

---

## 💡 Why Use It
- Open tools instantly  
- Stay keyboard-only  
- Easy to edit and extend
